# Pre-v1.0 work summary

[Archive index](README.md)

Historical summary, organized on 2026-11-03. This records the direction of the
pre-v1.0 work, not a live release gate or an assertion that all platforms passed.
Use [maintenance checklists](../maintenance/README.md) to validate a build.

## What the original plan covered

1. Code cleanup and performance baselines.
2. App-wide themes.
3. Lower rendering/input overhead, especially on handhelds.
4. Wine/Proton compatibility.

## Implemented areas

- Virtual library grid, bounded caches and disk-backed cover thumbnails.
- Reduced controller IPC noise without slowing the native desktop-pointer poll.
- Six built-in themes, custom-theme editing and import/export.
- Handheld presentation workarounds, activity-triggered Wine repaint nudges
  and bundled fonts with Wine-specific rendering fixes.
- Serialized settings updates to avoid lost overlapping saves.
- Touch classification, duplicate-tap protection and controller/touch handoffs.
- Steam game shortcuts, running-state tracking and queued edits while Steam runs.
- Shared owned panels, controller-friendly pickers and virtual keyboard loading.
- Independent CRT/bezel settings and GPU-based reflection sampling.
- Signed source updates with temporary provider disable/restore policy.

These items describe available implementations, not universal gameplay or
hardware compatibility. Current behavior belongs in the
[documentation index](../README.md), especially [Platforms](../PLATFORMS.md),
[Appearance](../APPEARANCE.md) and [Performance](../PERFORMANCE-BASELINE.md).

## Important conclusions from testing

- Native Windows DirectComposition stalls and Wine's last-frame presentation
  issue were distinct problems; one workaround should not replace the other.
- A VM could validate settings persistence and basic input but could not
  reproduce every real AMD handheld presentation problem.
- Switching ANGLE to OpenGL reduced stale UI but hurt game performance, so it
  was not retained as the normal solution.
- Steam can rewrite non-Steam shortcuts from memory; editing its file directly
  while it is running was not a durable solution.
- Wine touch does not consistently identify itself as browser touch input.
- Theme-native controls now follow the app theme, not a forced dark mode or
  the host desktop's reported scheme.

## Still requiring judgment or release validation

- N v2 repeated-episode loading slowdown was not established as a host-rendering
  fix. Upstream Ruffle reports are leads, not proof of the same root cause.
- Hardware/OS smoke tests are not exhaustive release certification; repeat
  tests against the final package, including Steam Gaming Mode where relevant.
- Distribution permissions, corresponding source and notices require their
  own [license review](../LICENSE-AUDIT.md).

Detailed measured samples and their limitations are retained in
[Performance notes](PERFORMANCE-NOTES.md). Historical bundle sizes, temporary
experiments and earlier hypotheses should not be copied into current guides
as present-day guarantees.
